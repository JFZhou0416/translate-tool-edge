# 屏幕翻译（自用 AI 版）· Edge 扩展

> 动机：Edge 自带的网页翻译**术语不可控**、整页替换**原文就没了**。
> 这个扩展换成自己那套 AI 翻译（`deepseek-v4-flash` + 关思考），并且把译文**插在原文下方**，随时一键还原。
>
> 计划书：`屏幕翻译-Edge插件与桌面版-计划书.md`（zcode 写）
> 安卓版（一期，已交付）：`<本地路径>`

## 它长什么样

- 小字、左侧一条竖线，插在**原段落下方**（颜色可在设置里改：自动 / 浅色 / 深色 / 自定义）
- ⭐ **自动配色看的是"页面自己的背景亮度"**，不是系统主题 —— 深色网站在浅色系统下照样看得清（NexusMods 那种）
- 原文不动、排版不乱
- 随时「还原」——所有译文节点带统一 class，一次全清
- 术语表沿用安卓版格式（`原文=译名`，全角 `＝` 也认）
- ⭐ **区域翻译**：在页面上**拖一个框**就行 —— 框里能取到 DOM 文字就按老办法插译文（快、带对照），
  取不到（图片 / Canvas / SPA 烂结构）就自动**截图送多模态识图**，结果浮在框旁边的卡片里（见下面「区域翻译」）

## 怎么装（加载解压版，零审核）

1. 打开 Edge → 地址栏输入 `edg<本地路径>`
2. 右上角打开 **开发人员模式**
3. 点 **加载解压缩的扩展** → 选这个目录：`<本地路径>`（工作副本，以此为准）
4. 装好后点扩展图标 → **设置** → 填 API Key → **保存** → **链路自检**
5. 顺手看一眼 popup **底部**的版本号（如 `v0.3.1`）—— 每次更新后拿它核对"重载成功没"（见下面「交付约定」）

## 🔁 交付约定（每轮改完必做）

1. **升版本**：每轮改完把 `manifest.json` 的 `version` 升一档（第 3 轮 `0.1.0 → 0.2.0`、第 4 轮 `0.2.0 → 0.3.0`、第 5 轮 `0.3.0 → 0.3.1`；小修 `+0.0.1`、加功能 `+0.1.0`）。
   popup **底部**就显示当前版本（如 `v0.3.1`）—— 老板拿它核对"更新到底装上没"。
   ⚠️ **`manifest.json` 的 `version` 和 `src/content.js` 里的 `SCRIPT_VERSION` 必须一起升**（popup 拿这两个值比对，
   只升一个会变成"刷新了还报『本页需刷新』"）；只有消息格式不兼容时才动 `content.js` 的 `PI`，同时把 `popup.js` 的 `NEED_PI` 改成一样。
2. **提醒用户「重载 + 刷新」**：解压版扩展**不会自动重载**，**已经打开的页面更不会自己换来新脚本**。
   所以每次交付都要带一句：**「在 `edg<本地路径>` 点『重新加载』→ 再刷新页面（F5）」**。
3. **页面跑着旧脚本时**：popup 一打开就会在**顶部出红条**「本页需刷新一次（F5）才能用新功能」，
   点红条里的「**刷新本页**」按钮即可（等价于按 F5）。
   若页面根本注入不了（`edg<本地路径>` 内部页、没开「允许访问文件 URL」的 `fil<本地路径>` 页…），红条文案会换成「本页无法使用扩展…」。
   → 这条是**治本**的：以后不会再出现"点了没反应、也没有任何提示"。

## 怎么用

| 操作 | 方式 |
|---|---|
| 翻译本页 | 点扩展图标 → 「翻译本页」／快捷键 `Alt+Shift+T` |
| 区域翻译 | 点扩展图标 → 「🔎 区域翻译（拖框，万能）」／快捷键 `Alt+Shift+R` → 在页面上拖一个框 |
| 试水 | 弹窗里「试翻 5 段」（先花一次调用的钱看看效果）|
| 还原 | 「还原」／默认没有快捷键（`Alt+Shift+R` 已让给区域翻译）（连进度一起清） |
| 长页面翻不完 | 翻完一批（默认 300 段）后 popup 会给「**一键翻完剩余 x 段**」—— 点一次就自动接着翻完（翻的时候按钮变「⏹ 停止」，点了停在当前那一批）；刷新页面后再点它还能接着翻 |
| 只翻某几段 | popup →「**选段翻译（只翻我点的几段）**」→ 在页面上点要翻的段落（可多选）→ `ESC` 开始翻 |
| 翻译一整块（图片 / SPA 烂结构也行） | popup →「**🔎 区域翻译（拖框，万能）**」→ 在页面上**拖一个框**，剩下自动选路 |
| 设置 | 弹窗 → ⚙️（API Key / 模型 / 术语表 / 每页上限）|

## 🔎 区域翻译（拖框，万能）

**什么时候用**：整页翻译在 SPA 站点（比如 X/推特）只能选到碎片的时候，或者你想翻的是一张图、一个 Canvas、
一块结构很烂的区域 —— 拖一个框就行，剩下交给扩展自动挑最合适的那条路。

怎么用：点扩展图标 →「**🔎 区域翻译（拖框，万能）**」→ 在页面上**拖一个框**（快捷键 **`Alt+Shift+R`**，不用先去点扩展图标）。
（`ESC` / 右键 / 再点一次这个按钮 → 退出，页面一个字节都不改。）

**它是怎么选路的**（提示条上会短暂显示「文字路」/「截图路」，方便排障）：

| 路 | 什么时候走 | 你会看到 |
|---|---|---|
| **文字路**（快、带对照） | 框内用 3×3 采样拿到足够 DOM 文本：拼起来 ≥ 12 字 **且** 有 ≥ 1 个「够格段落」（单个元素自己的文本 ≥ 12 字） | 译文直接插在原文下方（和整页翻译同一个观感），同时给一张结果卡片 |
| **截图路**（兜底） | 取不到文字：图片 / Canvas / SPA 碎片（一堆几字的小 `<span>` 拼起来超过 12 字，但没有一段够格）、导航区、我们自己的译文节点 | 自动截图 → 裁剪 → 压缩 → 送多模态识图，译文放在浮在框旁边的**结果卡片**里 |

**结果卡片**：可拖动（拖标题栏）、`✕` 关、点页面空白处也会关；按钮有「复制」「看原文/看译文」，
文字路还多一个「插入到原文下方」（已经插过的不会再重复插）。卡片脚注写明这一趟走的是哪条路 + 用的模型 + 耗时。

**两处护栏**：

- **防等待过久**：框选面积超过视口 40% 时，提示条会提醒「框小一点更准（小字放大会更清楚）」—— 只是提醒，**不禁止**。
- **缓存**：同一个页面 + 同一个矩形（±4px）+ **5 分钟内**再翻一次，直接用上次的识图结果，不再花一次钱。
  缓存放在 `chrome.storage.session` 里 —— **浏览器关掉就没了**，不落盘。

**截图尺寸**：长边 ≤ 1280、JPEG q85（仍超过 400KB 就逐档降质量，最低到 q50）—— 和安卓端同一套规格。

### 🔒 截图隐私说明

**框选截下来的图只用于当次识别、不落盘、不外传**：

- 图片只在内存里裁剪 + 压缩，**不写进磁盘、不进下载目录、不进浏览器缓存**；
- 除了**当次**发给识图接口（`http<本地路径>`）那一次请求，不发往任何别处；
- 缓存里存的是**识别出来的文字**（以及矩形、模型、时间戳），**不是图片**；缓存随浏览器会话结束消失；
- 「还原」不会动缓存（缓存是「同位置翻过的记忆」），浏览器关掉即清空。
## ⚠️ 已知限制（一期接受，见计划书 §3.9）

| 限制 | 原因 |
|---|---|
| Edge 的 **PDF 阅读器里可能不生效** | 它是内置扩展，content script 进不去它的影子 DOM |
| iframe 里的内容不翻 | 一期只处理顶层文档 |
| 动态加载的新内容不会自动翻 | 需要再点一次（`MutationObserver` 留二期）|
| 长页面分段翻 | 不再硬砍：一次翻一批（默认 300 段），点「一键翻完剩余」自动接着翻（可停）；单块 25s 超时 + 失败自动重试 1 次 |
| 区域翻译的截图路 | 需要 `activeTab` 授权（点扩展图标即得）。拿不到授权/页面不允许时**不崩**：一句人话提示 + 退化成「仅文字路」 |
| 区域翻译的判定阈值 | 「够格段落 ≥ 12 字」是**我们的经验值**：碎片型 SPA（X 那种）会自动走截图路；如果真机上判歪了，改 `content.js` 里 `REGION_MIN_PARA` 一个数即可 |

## 🔒 关于 API Key

浏览器没有 AndroidKeyStore 那种密钥库 —— **`chrome.storage.local` 就是明文**躺在浏览器配置目录里。
自己用可以接受；**要分发给别人之前，务必在 README / 说明里写明这一点**。

（可选加固，本期没做：写个本地转发小服务，key 只放服务里，扩展只连 `127.0.0.1`。）

    stub-dom.js         自检用的迷你 DOM + chrome 桩（下面两个脚本共用；不启动浏览器）

## ⭐ 一条最容易踩的约束

**`fetch` 必须在 background（service worker）里发，不能在 content script 里发。**

content script 的请求会带上"当前页面"的 origin → 受页面 CORS 约束 → 大概率被拦；
service worker 属于扩展自身身份，配合 `manifest.json` 里的 `host_permissions` 才能跨域。

→ 所以架构是：content 只碰 DOM，文本用 `chrome.runtime.sendMessage` 交给 background 翻译，结果回传再插入。

## 翻译请求怎么调（一次一块 / 关思考）

- **不逐段发**：把段落编号 `[[1]] [[2]] …`，按累计字符分块（默认 ≤2000 字符/块），**一块一次请求**
  → 一页通常 1~3 次调用
- **顺带治好"人名多种译法"**：同一块内一次性翻译，术语/人名在这块里天然一致
- **关思考**（`thinking: {type:"disabled"}`）：防等待过久 —— 安卓版实测耗时减半（3.9s → 1.7s）

## 自测方法（不依赖人工）

1. **离线页面**：`test/test-page.html`（本仓库自带）
2. **独立临时配置启动 Edge**（绝不污染日常配置）：
   ```powershell
   & "<本地路径> Files (x86)\Microsoft\Edge\Application\msedge.exe" `
     --load-extension="<本地路径>" `
     --user-data-dir="$env:TEMP\st-edge-test" `
     --remote-debugging-port=9222 --no-first-run `
     "fil<本地路径>"
   ```
3. **看结果**：截图核对"译文是否插在原文下方、排版是否正常"；再点还原、再截图，与翻译前对比应一致
4. **术语验证**：设置里填 `vault=仓库`，整页应统一翻成同一个词
5. **API 规格**：不依赖浏览器，`python tools/api_smoke_test.py`（key 走环境变量 `DEEPSEEK_KEY`）——
   真打一次请求，验编号协议 `[[n]]`、术语表是否生效、耗时（>25s 会 NG，因为扩展侧超时就是 25s）
6. **译文外观**：设置页「③ 译文外观」改成深色/自定义后，已打开的页面**下次交互即生效**（不用重装扩展）
7. **一键静态自检（不启动浏览器、不联网、不花钱）**：在仓库根跑
   `node tools/static-check.js; node tools/selfcheck.js; node tools/region-check.js`
   —— 三段都全 PASS 才算干净；`selfcheck.js` / `region-check.js` 顺带把完整输出写到
   `tools/selfcheck-output.txt` / `tools/region-check-output.txt`（生成物，可删）。
   （分隔符：**PowerShell 用 `;`**、bash/cmd 用 `&&` —— 三段都是独立脚本，先后跑一次即可。）
8. **区域翻译（拖框）**：真机上随便找个图片块拖一个框 → 应走截图路并弹出卡片；
   再找个正常文章段落拖框 → 应走文字路、译文插在原文下方。判定结果会显示在顶部提示条上。
